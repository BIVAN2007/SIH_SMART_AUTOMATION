# Live Browser Demo

Just double-click `live_demo.html`, or drag it into any browser (Chrome,
Safari, Firefox all work — no server, no install).

This is a self-contained, in-browser simulation — good for quickly
showing the concept to someone without setting up the full stack. It's
not connected to the real backend (folder `04_backend_api`); it runs its
own lightweight copy of the same planning logic entirely in JavaScript.

For the real, database-backed, deployable version, use
`04_backend_api` + `05_frontend_dashboard` together instead.
